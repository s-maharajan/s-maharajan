### The work

I help move large middleware estates without stopping the business. That means treating migration as an engineering discipline: understand the landscape, make the dependencies visible, and change one reliable seam at a time.

```text
discover → map → modernise → operate
```

### Current focus

Building practical CLI agents for the unglamorous, high-leverage work: discovery, mapping, and repeatable delivery. Let the agents handle the evidence and the grunt work; leave judgement with the people who own the system.
